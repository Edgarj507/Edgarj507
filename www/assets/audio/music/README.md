# Custom music

Drop one file here, named exactly:

```
theme.mp3
```

If present, it replaces the built-in generated synthwave track (looping) when
the player toggles MUSIC: ON. If it's missing, the game falls back to the
generated track automatically - nothing else needs to change.

MP3 is required (not ogg/wav/m4a) for broad compatibility, including iOS
Safari/WKWebView where this game also runs as a native app shell.
